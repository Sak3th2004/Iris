# Try the live agent

1. Keep Docker Desktop running and open **http://127.0.0.1:8768**. The top of the browser panel should say **Live · Linux browser**.
2. Choose a suggestion under the instruction box. Suggestions use current database records and select a different day or quantity. Or write your own precise instruction using a visible guest/buyer name.
3. Choose **Review permission**. Check the record, exact change, protected fields and version. If Iris asks a question, rewrite the sentence with the missing detail.
4. Choose **Start agent**. The stage indicator moves to **Agent works**. The grey glow indicates an active connected job; the focus outline and pointer show the actual browser control being used.
5. Watch, expand, or hide the live view. You can close the owner page and return later. Keep the computer awake and Docker running. **Stop agent** revokes the permission; it cannot undo a write that already committed.
6. Completion is confirmed by a **database receipt**, including actual fields and version. An agent status message alone is not proof of completion.

The browser is deliberately inside the interface: it is a read-only window into the separate execution environment. You do not click inside the image to operate it. The **manual test desks** are separate owner controls for setting up invented data and exercising fault cases.

**Build status** lists verified capabilities and unfinished submission work. The core loop has completed booking and order tasks. Cal.diy interception, voice end-to-end verification, adversarial browser trials, held-out measurement, recovery hardening and the final video remain. Baseten Spark Open is now the default independent reader and requires BASETEN_API_KEY; see [setup](BASETEN.md). Meta still supplies the parser and planner.

The stack already uses open-source FastAPI, SQLite, Playwright and container tooling. Additional packages are chosen to solve a demonstrated problem, not to inflate the feature count. No extra API key or installation is required to try the current running build.
